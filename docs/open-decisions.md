| DA-0008 | What the repository root presents now that the repository is `esliph/agent-plugins`, a marketplace meant to host plugins that are not about documentation. The root `README.md` and `CLAUDE.md` still present the whole repository as `@esliph/living-docs`, and neither `packages/living-docs/` nor `packages/ownership/` has a README of its own. `ADR-0027` names the root `esliph` and does not say what its presentation and agent contract cover. Options: the root becomes the marketplace's page (the list of plugins and how to install them) and the toolkit's presentation moves to `packages/living-docs/`, with a README per package; the root keeps presenting living-docs until a second domain plugin exists; or the root README becomes the marketplace's page while `CLAUDE.md` stays as the living-docs agent contract, since this repository keeps using the toolkit on itself | resolved | ADR-0035    | `README.md`, `CLAUDE.md`                          | 2026-09-29 |
